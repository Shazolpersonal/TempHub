# Template Preview Images

This directory contains preview images for templates.

## Current Templates

- `time-magazine.jpg` - Preview for TIME Magazine Cover template
- `influencer-product.jpg` - Preview for Influencer Product Shot template
- `superhero-character.jpg` - Preview for Superhero Character template

## Image Requirements

- Format: JPG, PNG, or WEBP
- Recommended size: 800x600px or similar aspect ratio
- File size: Keep under 500KB for optimal loading

## Adding New Previews

When creating new templates, add corresponding preview images here and reference them in the template data as `/template-previews/filename.jpg`.
